# V1 is a portfolio RAG, not job-fit comparison

The earlier planning docs framed `compare_to_role` as the V1 killer feature, but the product scope is now a public portfolio RAG that answers questions about Joao. V1 should prioritize retrieval quality, cited answers, and a polished portfolio chat experience; job-description comparison, JD parsing, and requirement-level fit analysis are out of scope unless deliberately reintroduced later.
